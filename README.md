## Sobre mim

Oi, sou o **Raphael Sparda**.

Atuo como desenvolvedor full stack e acredito que construir páginas é um verdadeiro ato artístico, onde composição, ritmo e detalhe importam tanto quanto o código.

> "A arte é a mentira que nos permite conhecer a verdade."
> **— Pablo Picasso**

No meu trabalho, trato design e código exatamente assim: pequenas ficções criadas para revelar o que realmente importa para os usuários.

Curto experimentar novas tecnologias e levar soluções do protótipo à produção com qualidade e clareza. O que busco entregar é uma beleza que guia, uma performance que acolhe e uma acessibilidade que abre portas.
